# royal-larch-lite



学习用的示例项目

## 用法

```bash
cat data.txt | node index.js
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/royal-larch-lite.git
cd royal-larch-lite
npm install
```
